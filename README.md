# Quốc Chiến

Game chiến thuật offline, chạy trên web, cài lên iPhone dạng PWA.

Game tự xây, tự sản xuất, tự phát triển — người chơi **chỉ ra quyết định**.
Một ván đi suốt sáu thời đại: cổ đại → trung cổ → súng ống → công nghiệp → hiện đại →
tương lai. Đồ hoạ 2D isometric, sprite nướng từ model 3D CC0.

- Thiết kế game: [`docs/GAME_SPEC.md`](docs/GAME_SPEC.md)
- Kỹ thuật và trần hiệu năng: [`docs/TECH_SPEC.md`](docs/TECH_SPEC.md)
- Kế hoạch 13 phase: [`docs/KE_HOACH.md`](docs/KE_HOACH.md)
- Luật làm việc cho Claude: [`CLAUDE.md`](CLAUDE.md)

Chưa có bản chơi được. Đang ở Phase 0 — dựng khung repo.
